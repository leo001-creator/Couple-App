# ❤️ Our Little World

GitHub Pages friendly iPhone PWA.

## Included
- ❤️ Days Together: days + hours + minutes + seconds
- 💗 Love Meter with animated heart
- 🎵 Our Song with optional external link
- 🏠 Our Little World home screen
- ✨ Cute Surprise button
- 📱 PWA manifest + service worker
- 💾 LocalStorage for settings

## GitHub Pages
1. Create a repository and upload all files.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Open the HTTPS GitHub Pages URL in Safari.
6. Safari → Share → Add to Home Screen.

## Note
This version stores data only on the current device. It does not yet sync between two phones. For shared couple data, connect Supabase/Firebase in a later version.
